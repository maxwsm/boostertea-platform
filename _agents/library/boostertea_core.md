# 🧠 Сферична Бібліотека: Ядро BoosterTea (MVP Контур)

**Статус:** Verified & Locked (Protocol 13)
**Дата:** 2026-03-31
**Фокус:** Конверсія та Стабільність

Цей документ виступає "Відбитком" (Snapshot) робочої, безпомилкової архітектури для продажу ключових концентратів, згідно з догмою 0.3% Профіту.

## 1. Архітектура Каталогу та UI 🛒
* **Бібліотека Знань:** Усі товари існують в єдиному глобальному масиві пакету `@wsm/config`. Але для BoosterTea MVP ми впровадили **Жорсткий Фільтр**: відображуються лише 3 об'єкти (Pu-erh, Da Hong Pao, GABA).
* **Спрощений UI:** Важкі WebGL компоненти, лідерборди та Instagram-фіди блокували воронку. Вони були вирізані з `index.tsx` на користь 100% прямого шляху: УТП -> Товар -> Кошик.

## 2. Логіка Чекауту та Оплати 💳
1. **Кошик:** `SmartCartDrawer` збирає замовлення і перевіряє активність автопілоту. 
2. **Форма Чекаута (`client.tsx / checkout.tsx`):**
   - Тільки Нова Пошта або Самовивіз (Львів).
   - `POST /api/orders` перехоплює лід.
3. **БД та Транзакції:** Створення замовлення локально через `prisma.order` та `prisma.transaction` зі статусом PENDING/FROZEN. Це захист від Double-Spend.
4. **Оплата Mono:** Формування інвойсу через `POST /api/payment/create-invoice`.
5. **Webhooks:** `/api/webhooks/monobank` чекає на відбій. Якщо успішно — статус COMPLETED і пуш-евент в Meta CAPI/GA4.

## 3. Telegram Комунікації (Пасивні vs Активні) 🤖
* **Пасивна Нотифікація (Обов'язкова):** При створенні ордера бекенд (`/api/orders`) пушить повідомлення з даними клієнта у Admin Telegram Group. Працює стабільно і синхронно.
* **Активний AI (Gemini Agent):** Опрацьовує `bot.on('text')`. Щоб запобігти галюцинаціям та спаму у робочій групі, встановлено жорсткий фільтр: `if (ctx.chat.type !== 'private') return;`. Бот мовчить всюди, окрім особистих повідомлень з клієнтами.
* **Healthcheck Спам (Усунено):** Інфраструктурний скрипт `02-healthcheck.sh` генерував хибні спрацьовування "Container DOWN" під час PM2-серв-деплоїв. Він вимкнений до побудови власного WSM Observability модулю.

## ⚡ Висновок
Цей еталонний контур є фундаментом для клонування інших брендів (FunnyDrops, T-Lab). 
Щоб розгорнути новий бренд, необхідно змінити лише масив товарів та `merchantId` для MonoBank-ключів. Увесь інший двигун — 100% універсальний.
