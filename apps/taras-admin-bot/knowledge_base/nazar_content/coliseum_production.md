# Coliseum: Знімальна Площадка та Виробництво (YouTube, TikTok, Reels)

Проект **Coliseum** — це не просто офіс, це професійна кіно-платформа для брендів екосистеми (BoosterTea, Aqua 360, та інші).

## 🎥 Апаратна Моторика (Світло та Техніка)
- **Фони та декорації:** Кожен бренд має свою візуальну зону. Aqua 360 — біологічна лабораторія / неоновий синій; BoosterTea — кібер-урбаністика / неоновий зелений.
- **Освітлення:** Використовуй триточкове освітлення. Ключове світло (Key light) завжди під кутом 45 градусів. Заповнююче світло для пом'якшення тіней і контура для відокремлення спікера.
- **Зйомка:** Пишемо в 4K 60fps (щоб мати запас по кропу без втрати якості). Для TikTok рендеримо строго у 1080p, інакше алгоритми платформи жорстко стиснуть відео з артифактами.

## 📺 YouTube: Довгий Метр
Ютуб працює на аудиторію "Гарячого" рівня усвідомленості. Там люди шукають вдумливі огляди, вирішення глибоких проблем.
1. **SEO:** Назви відео та теги мають чітко попадати в запити (напр. "Як очистити ставок від водоростей - Aqua 360", "Відкриваємо магазин Bubble Tea").
2. **Структура:** Хук (0-15 сек) -> Інтро (15-30 сек) -> Основне М'ясо (втримання) -> Call to Action (Підпишись/Купуй).
3. **Обкладинки (Thumbnails):** 50% успіху відео. Високий контраст, емоційне обличчя, мінімум тексту (великий читабельний шрифт). 

## 📱 Short-Form Контент (Reels / TikTok / YouTube Shorts)
Тут ми конвертуємо хаотичну увагу в капітал. 
- **Правило 3-х Секунд:** Здивуй, покажи парадокс або відразу ріж до болю (Pain Point). Без паузи на "всім привіт".
- **Динаміка:** 1 секунда = 1 подія (текст на екрані, зум, рух камери, звуковий ефект). 
- **Моторика:** ASMR-шоти з переливанням BoosterTea або макро-зйомки реакцій бактерій Aqua 360 — залипання гарантоване.
